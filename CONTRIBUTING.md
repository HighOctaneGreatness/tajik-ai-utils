# Contributing

Contributions are welcome.

This project focuses on practical Tajik-language utilities for AI, NLP and dataset preparation.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Add tests for new behavior.
4. Run the test suite.
5. Open a pull request with a clear description.

## Development setup

```bash
git clone https://github.com/HighOctaneGreatness/tajik-ai-utils.git
cd tajik-ai-utils
pip install -e ".[dev]"
pytest
```

## Contribution ideas

- Improve transliteration rules
- Add more Tajik normalization cases
- Add CLI commands
- Add dataset validation helpers
- Add examples for RAG pipelines
- Add documentation in Tajik and Russian
